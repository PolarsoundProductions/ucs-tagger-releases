# UCS Tagger — release info

This repository holds one small file, [`latest.json`](latest.json), that UCS Tagger
reads to tell you when a new version is available.

- The app downloads this file at startup (at most once a day; switch it off in
  **Settings → Updates**) and when you click **Check for updates**.
- Nothing is sent along with that request — no license key, no machine ID, no
  version number, no usage data. The version comparison happens in the app.
- UCS Tagger never downloads or installs updates by itself. New versions are on
  Gumroad: https://polarsoundproduction.gumroad.com/l/ucs-tagger
